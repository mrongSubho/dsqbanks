# NSDA Data Science Level 4 Question Bank

Independent study resource for the NSDA Data Science Level 4 exam — **974 questions** across 6 units, including MCQs, short questions, and practicals.

**[View Live](https://nsda.me/data-science)**

## Features

- **Filter & Sort** — Toggle between MCQ / Short Questions / Practical sections; sort by source order, difficulty, or A–Z
- **Show Answers** — Toggle answer visibility on/off across MCQs, short questions, and practicals
- **Practical Sets** — 3 practical sets with tabbed interface (Set 1/2/3); each contains 3 questions with 4 tasks; collapsible code, output, and solution sections
- **Text-to-Speech** — Hover any question to hear it read aloud; supports different voices, speed control, and auto-scroll
- **Difficulty Tags** — Each question tagged M (Must Know), S (Standard), K (Should Know), C (Could Know)
- **Progress Bar** — Colorful dynamic progress bar works across all sections (MCQ, short, and practical); shows unit/set and question position
- **Correction Badges** — 10 source-answer errors identified and flagged with ⓘ badges showing the correct answer
- **Unit Navigation** — Bottom nav strip with dots and prev/next buttons; hidden by default, appears on hover; hidden in practical section
- **Practice Test Generator** — Configurable test at `test.html` with randomized questions across MCQ, short, and practical sections; supports drag-to-reorder sections, adjustable counts/marks/time; print test paper or answer key
- **PWA** — Installable as a standalone app on mobile and desktop; works offline via service worker; automatic update notification with one-click refresh
- **Back to Top** — Floating button appears on scroll
- **Disclaimer** — Unofficial student-created resource, unaffiliated with NSDA

## Build

Pure HTML/CSS/JS — no build tools needed. Open `data-science/index.html` in any browser.
