What is 'regularization'? Name TWO types.

Two types:
1. L1 (Lasso) — adds the absolute value of weights to the loss. Can reduce some weights to exactly zero, acting as feature selection.
2. L2 (Ridge) — adds squared weights to the loss. Shrinks all weights smaller but keeps them all — reduces complexity without removing features.

What is 'one-hot encoding'? When should you use it instead of label encoding?
One-hot encoding creates a separate binary (0/1) column for each unique category value.
Example: A 'Colour' column with Red/Blue/Green becomes three columns: Colour_Red, Colour_Blue, Colour_Green.
Use one-hot encoding when the categories have NO natural order — e.g., city names, colours, or product types. Label encoding (Red=0, Blue=1, Green=2) would wrongly imply Blue > Red and Green > Blue, which is not true for unordered categories.
16
What is the 'bias-variance tradeoff'? Explain with an example.
The bias-variance tradeoff is the balance between two types of model error:
- High Bias = underfitting (model too simple, misses patterns, wrong on training AND test data)
- High Variance = overfitting (model too complex, memorises training data, fails on test data)
Example: A straight line through house price data (high bias) misses the curve in the relationship. A complex curve that passes through every training point (high variance) fits training perfectly but predicts badly on new houses. The best model finds the middle — complex enough to capture the real pattern, but not so complex it memorises noise.
17
What is 'SMOTE'? Why is it used?
SMOTE (Synthetic Minority Over-sampling Technique) is a technique that creates new artificial examples of the minority class to balance an imbalanced dataset.
How it works: SMOTE selects a minority class example and finds its nearest minority class neighbors. It then creates new synthetic examples at random points along the line between them.
Why used: In imbalanced datasets (e.g., 95% not-fraud, 5% fraud), models tend to ignore the minority class. SMOTE gives the model more minority examples to learn from, improving Recall and F1 Score for the rare but important class.

One-hot encoding should be used for unordered categories like colour or city, where assigning integers would imply false ordering.

What is the 'Elbow Method'? Describe how to use it.
The Elbow Method is used to choose the best number of clusters (K) for K-Means clustering.
How to use it:
1. Run K-Means for values of K from 1 to 10 (or more).
2. For each K, calculate the WCSS (Within-Cluster Sum of Squares) — a measure of how spread out points are within each cluster.
3. Plot WCSS against K. As K increases, WCSS decreases.
4. Find the 'elbow' — the point where WCSS stops decreasing sharply and begins to flatten. This bend in the curve is the optimal K.
Example: If WCSS drops steeply from K=1 to K=4, then flattens, K=4 is the best choice.

What is 'dropout' in neural networks? Why does it help prevent overfitting?
Dropout is a technique where random neurons (nodes) are turned off during each training step. The percentage turned off is called the dropout rate (e.g., 0.3 = 30% of neurons dropped each step).
It helps prevent overfitting because it forces the network to not rely on any single neuron. The network must learn multiple independent ways to make correct predictions, making it more general and robust to new data.

What is 'batch normalization'? What problem does it solve?
Batch normalization normalises the inputs to each layer during training, keeping values in a consistent range with mean near 0 and standard deviation near 1.
Problem it solves: as neural networks train, the distribution of values in each layer can shift dramatically, making training slow and unstable. Batch normalization prevents this 'internal covariate shift', allowing the use of higher learning rates and resulting in faster, more stable training.

What is 'ROC-AUC'? Explain what a good AUC score looks like.
ROC-AUC stands for Receiver Operating Characteristic — Area Under the Curve.
The ROC curve plots True Positive Rate (Recall) against False Positive Rate at all possible classification thresholds.
AUC is the area under this curve:
- AUC = 1.0: perfect model — correctly separates all positives from negatives
- AUC = 0.5: model is no better than random guessing
- AUC > 0.8: generally considered a good model
AUC is preferred over accuracy for imbalanced datasets because it measures the model's ability to rank positives above negatives regardless of class distribution.

Explain 'Precision' and 'Recall'. When would you prioritise Recall over Precision?
Precision = TP / (TP + FP): of all predictions marked positive, how many were actually positive? High precision = few false alarms.
Recall = TP / (TP + FN): of all actual positives, how many did the model find? High recall = few missed cases.
Prioritise Recall when missing a positive case is very costly:
- Cancer screening — missing a malignant tumour is life-threatening
- Fraud detection — missing a fraudulent transaction costs money
In these cases it is better to have more false alarms (lower precision) than to miss true positives.

What is 'overfitting'? How can it be reduced?
Overfitting happens when a model learns the training data too well — including noise — and performs poorly on new data.
Two ways to reduce it:
1. Use more training data so the model sees a wider variety of examples.
2. Simplify the model (e.g., limit the depth of a Decision Tree) so it cannot memorise the training data.

Name THREE pre-processing steps used to prepare data before training a model.

2. Encoding — converting text categories (e.g., 'Male', 'Female') into numbers (0, 1) that the model can process.
3. Normalization or Standardization — scaling all feature values to the same range so no single feature dominates the model.

What is the 'Confusion Matrix'? Name its four parts.
A Confusion Matrix is a table that shows how many predictions a model got right and wrong.
Four parts:
1. True Positive (TP) — correctly predicted Yes.
2. True Negative (TN) — correctly predicted No.
3. False Positive (FP) — predicted Yes but actually No (false alarm).
4. False Negative (FN) — predicted No but actually Yes (missed case).

K-Means clustering is an unsupervised algorithm that divides data into K groups of similar items.
How it works:
1. Choose K (the number of clusters).
2. Randomly place K centre points in the data.
3. Assign each data point to the nearest centre.
4. Move each centre to the average of its assigned points.
5. Repeat steps 3–4 until the centres stop moving.
Result: K groups of similar data points.

High Precision = few false alarms. High Recall = few missed cases.

Compare Apache Spark and Hadoop MapReduce. Why is Spark faster?
Both process large datasets across many machines in parallel, but they differ in how they handle intermediate results.
MapReduce: writes intermediate results to disk (HDFS) after every Map and Reduce step. Disk read/write operations are slow, creating major bottlenecks for multi-step tasks.
Spark: keeps intermediate results in memory (RAM) and passes them directly to the next step without disk writes. This avoids the disk I/O bottleneck.
Result: Spark can be 10–100 times faster than MapReduce for iterative tasks like machine learning, where data is processed many times.

What is 'MapReduce'? Explain the Map and Reduce steps using a word count example.
MapReduce is Hadoop's data processing method that divides large tasks into small parallel sub-tasks across many machines.
Example — counting words in 10 GB of text:
Map step: HDFS splits the text into many blocks, each sent to a different machine. Each machine runs a Map function on its block, outputting a key-value pair for every word: ('hello', 1), ('world', 1), ('hello', 1).
Shuffle (automatic): All pairs with the same key are collected and sent to the same machine.
Reduce step: Each machine receives all pairs for certain words and sums them: all ('hello', 1) pairs → ('hello', 4,250). Final result: a complete word count across the entire 10 GB file.
